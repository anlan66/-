# OKX 交易分析系统

一个纯前端、单文件的加密货币交易记录与分析工具，通过 OKX API 拉取交易记录，并提供盈亏统计、胜率分析、价格行为学 / 缠论标记等功能。

## 功能

- 连接 OKX API，拉取并查看交易记录
- 仪表盘统计：总交易数、总盈亏、胜率、盈亏比
- 按策略（价格行为学 PA / 缠论 Chan）标记交易并统计胜率
- 交易明细列表、搜索、导入 / 导出 JSON 数据
- 本地保存数据，无需服务器

## 使用

直接用浏览器打开 `crypto-tracker.html` 即可运行，无需安装依赖或构建。

在“设置”页填入 OKX API Key、Secret Key 与 Passphrase（建议使用只读权限的 API Key，并绑定 IP 白名单），点击“获取交易记录”即可导入交易数据。

## 安全提示

- 所有 API 凭据仅保存在浏览器本地，不会上传到任何服务器
- 请勿在共享或不受信任的设备上保存 API 凭据
